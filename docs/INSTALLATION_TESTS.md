# jellyflower installer and updater checks

Current release: 0.16.4. Step 24 records the retired Fluent Body experiment; use step 26 for current typography. Steps 21–23 describe retired font/network experiments; use 24–25 for current checks. Run these on the normal Windows desktop. The build environment's extract/JSON checks do not prove desktop registration or rendering.

1. Quit TranslucentTB and any other taskbar modifiers. Double-click jellyflower-setup-x64.exe on x64 Windows. Confirm installation succeeds without elevation, the flower appears under show hidden icons, and the Start menu shortcut launches the same instance.
2. Confirm Windows Settings > Apps > Installed apps lists jellyflower with the correct version. Task Scheduler should have one enabled jellyflower-<your SID> logon task and Startup apps one jellyflower Run fallback; upgrading the earlier AcrylicTaskbar build should remove its duplicate Run registration.
3. Sign out/in. Confirm jellyflower starts with acrylic system, retains saved cursor/clock choices, and the actual taskbar looks correct. Enable battery saver, check the process remains running, and separately record whether Windows supplies blur or a solid fallback.
4. Toggle Windows light/dark mode. The tray uses black/white ink and the app/Start shortcut uses the inverse icon variant. Explorer's static EXE-file icon remains the supplied default. Windows may cache the Start shortcut's icon briefly.
5. Select the installed version row (v0.16.4). Confirm checking and the rotating icon appear immediately, other rows respond, and no update notifications appear. Current release says up to date. Disconnect the network and retry; it should say try again. Close during a request: exit should be immediate, without a later installer launch.
6. For a genuine later stable release with this architecture's installer and valid asset digest, select available. It should show downloading then installing, replace/relaunch jellyflower, and show the new version. No browser, manual EXE launch or success dialog should appear. Saved date/cursor/auto preferences and the cursor ZIP should survive. Repeated clicks must not launch duplicate transfers or setup. Drafts/previews/missing architecture or digest must not be offered.
7. Disconnect during download or close before installation starts. The old installed version must remain usable; no partial executable may launch. For a controlled test build, inject corrupt/truncated bytes and an installation failure after stopping; verify rejection and attempted restoration of startup, uninstall registration, shortcut and old controller. Verify both a standard installed app and portable-to-installed upgrade. Restart Explorer/sign out only if helper code changed. A controller version alone cannot prove helper reload.
8. Choose exit. Confirm clock/calendar/tooltip, speaker, chevron, taskbar material/border, and configured Windows cursor scheme restore. Relaunch from Start. Uninstall from Installed apps and confirm login startup and the shortcut are removed. Windows may retain pinned helper files until Explorer exits.
9. On a computer without the optional cursor pack, a fresh launch should preserve its configured Windows cursors quietly. No personal cursor/font files should appear in setup or source archives.

10. On a fresh account without a pack, the root shows colors, unlock at the right, and a cycling preview using the supplied cursor shape. There must be no cursor chevron/submenu. Clicking it opens the TXT and import folder. The guide links the creator's full pack and displays the exact folder. Merely previewing colors must not change your system cursor.
11. Copy the original full ZIP into `%LOCALAPPDATA%\jellyflower\cursors` with the root menu open. Within ten seconds the row should become cursor with a chevron in place, preserving the configured Windows cursor. Its submenu must have the colors/default/disable and no unlock row. Select colors and default (system); verify roles/animations and automatic theme-following. Imported packs survive relaunch/updates.
12. Add a free, incomplete, invalid, or corrupt ZIP. Confirm it cannot replace a working imported pack or change the selected cursor. Replace the failed file with a fresh full ZIP and check retry. Relaunch and verify an unchanged ZIP is not imported again. Updates and uninstall should retain the user-owned ZIP/import folder.

See [TESTING.md](TESTING.md) for taskbar, cursor, menu, multi-monitor, focus, and calendar checks, and [VALIDATION.md](VALIDATION.md) for the checks completed in development.

13. Upgrade from 0.14.0 with its taskbar helper loaded. Setup should ask for one sign-out/sign-in. Until that happens, the new controller must not reuse the older helper. Sign out/in (or restart Windows Explorer once), then confirm the new tint and a modern attached diagnostic result.
14. Select acrylic system with a completely black wallpaper, first in light mode, then dark. Light mode should have an unmistakable white frost and readable dark taskbar text. Repeat with white wallpaper: dark mode should keep readable light text. Repeat on secondary monitors, after toggling pure/off/system, after theme changes, and after reopening Quick Settings/Start. Pure intentionally remains untinted and may be less legible. Off/exit must restore Windows' appearance.
15. Put a colorful detailed window behind the root menu and the nested cursor menu. In light and dark modes, check that the surface is softly blurred/translucent while text, glyphs, status labels, hover pills and focus indicators stay crisp. Move the underlying window to confirm this is a live backdrop. Settings should keep the menu open; outside clicks and tray-button toggling should still close it.
16. Turn Transparency effects off and on, enable energy saver, and test high contrast. Solid menu fallback should stay readable. Returning to normal settings should restore acrylic where Windows permits it. Check on Windows 10 or an older Windows 11 build: the unsupported backdrop API must leave a usable solid menu. These rendering checks cannot be established by successful API calls alone.

17. Date must be directly below acrylic in the root menu. Toggling it swaps the calendar/calendar-off glyph and right-side on/off text, changes the clock immediately, and keeps the same menu open. Relaunch and verify persistence. Upgrade with an old custom-font selection and confirm the clock uses the native system typeface without any font-file lookup. The calendar click, tooltip and lowercase am/pm must still work; exit restores the original two-line clock.

18. Leave a completed new-version installer dialog open, then run it again. It must not falsely report error 170. Two actively installing new setups must still exclude one another. Close or finish any actively working legacy setup before testing. Confirm error dialogs identify the failed step instead of always blaming another setup window.
19. Verify system is the first row, date immediately follows acrylic, and all labels remain lowercase, regular Segoe UI. Cycle light/dark/auto. Auto alone requests Windows location access. Deny: preserve the current theme and display location off. Allow with Location services on: switch according to local daylight, save the choice, and resume after login without explicitly asking for new consent. Disable/revoke location and test an unavailable provider; never invent a position or change to a default city. Manual light/dark must stop scheduling.
20. With a test clock/location provider, cross sunrise/sunset, UTC midnight, DST changes, sleep/resume and polar summer/winter. The scheduler should catch up after resume and not write the same preferences repeatedly. Travel refresh is daily, so changes of location can lag. Exit stops scheduling while leaving the last Windows theme. Compare text/icon sharpness at 100%, 150%, 200% and after moving menus between backgrounds. Transparency off/high contrast must produce a readable solid surface.


## 21. Windows 11 menu, network artwork, and tint (0.16.0)

1. Update from 0.15.0 using its version row; menu changes should apply after relaunch. Sign out/sign in once for the v10 helper. Confirm diagnostics no longer report revision mismatch. A fresh install needs no reload. Do not run competing taskbar stylers.
2. Compare menu text with Windows 11 taskbar popovers: Segoe UI Variable Text, regular weight, 14 effective pixels. Check primary/secondary text, both themes, and 100/125/150/175/200% DPI. No bold text, clipping, label/status collisions, or incomplete icons.
3. With the taskbar at the bottom, compare the 12 DIP bottom/right breathing room. Repeat on secondary monitors, including negative desktop coordinates, with the tray icon visible and in overflow. Menus and cursor submenus must stay within the monitor work area.
4. Open the flower: the main menu rises from below with a fast start and smooth stop over 250 ms. Repeated tray clicks, outside presses, Escape, live settings and immediate submenu selection during opening must remain responsive. Disable Windows animation effects and verify instant opening; restore your preference afterwards. This curve follows published Fluent guidance, not a verified private shell implementation.
5. While connected, inspect Element 2 at the native 16 DIP glyph size in both themes and each DPI. Check Wi-Fi signal changes and Ethernet. Temporarily disconnect using Windows controls: the native no-internet glyph must return immediately. Reconnect: Element 2 returns. Warning/connecting/unknown states must remain native. Keep Quick Settings click/tooltip/narrator behavior and battery intact. Exit restores the native connected glyph; relaunch re-applies it. Test Explorer restart and sleep/resume separately.
6. In acrylic system mode compare black/white/busy wallpapers in both themes. The tint is slightly stronger, with blur/background still visible. Pure must remain untinted. Check transparency off, high contrast, and battery saver for Windows-controlled fallbacks separately.

The native fixtures validate the adapter on a shell-shaped XAML tree and actual brush properties. They do not prove all future Explorer layouts, real network transitions, or GPU taskbar output. Unknown layouts are left untouched.


## 22. Network and lighter acrylic correction (0.16.1)

1. Upgrade from 0.16.0, then sign out/sign in once for helper v11. Menu text changes immediately; taskbar artwork/tint need the new helper. Confirm diagnostics are responsive, bridgeState is attached (2), and lastResult is zero.
2. In light and dark modes compare menu text: Segoe UI Regular, 14 effective pixels, at 100/125/150/175/200% display scaling. Confirm unchanged spacing, clear text, and no clipping or bold labels.
3. On connected Wi-Fi (including weak signal) and Ethernet, confirm the monochrome Element 2 vector replaces the native glyph, follows the shell theme, and diagnostics show replacedNetworkIcons greater than zero plus a networkGlyphCode. Network names must not be logged. Hover and click still show native network status and Quick Settings; battery is untouched.
4. Disconnect or use airplane mode. Confirm the Windows offline/airplane glyph returns immediately, and reconnect restores Element 2. Start the app offline, then connect. Test after docking or taskbar template replacement. Exit must restore the native artwork and its current opacity/binding.
5. With acrylic set to system, compare both themes over black, white, and colorful wallpaper. More background should show through than 0.16.0, while clock/taskbar labels remain readable. Pure stays untinted; off restores Windows. Confirm high contrast/disabled transparency/battery saver can still impose Windows' solid fallback.


## 23. Windows menu font and direct network layout (0.16.2)

1. Update from 0.16.1 and sign out/sign in once to load helper v12. Confirm the version row reads v0.16.2 and diagnostics are responsive, attached, and free of revision mismatch. A version row alone does not confirm helper reload.
2. Open root/cursor menus in both themes at 100/125/150/175/200% scaling. Windows supplies the font family, size and weight without overrides; on the development PC this is Segoe UI, 12 effective pixels, regular. DirectWrite/Direct2D supplies natural text layout and alpha rendering instead of the earlier GDI mask. Check sharpness at native screen resolution, text fit, secondary labels, and icon alignment against the desired Windows popover. Private shell components can choose their own type scale; this does not promise pixel-identical typography to every Windows surface. Check contrast/transparency fallback too.
3. Connected Wi-Fi at different strengths and Ethernet should show Element 2 in the native theme color. Check replacedNetworkIcons and networkGlyphCode in diagnostics. Disconnect, reconnect, start offline, use airplane mode, and dock/undock; native offline/warning/connecting icons must remain. Hover/click still show Windows network status/Quick Settings, battery remains native, and exit restores the original current glyph.


## 24. Fluent Body typography and native network icons (0.16.3)

1. Update and sign out/sign in once to load helper v13. Confirm the version row says v0.16.3 and diagnostics are responsive and attached without revision mismatch. A running controller version alone does not prove helper reload.
2. Compare both themes at 100/125/150/175/200% scaling. All primary/secondary labels follow the published Fluent Body role: regular Segoe UI Variable, 14 DIP, 20-DIP line height, with automatic optical sizing. Segoe UI is the compatibility fallback. Check clarity at native screen resolution, complete text, alignment and live menu backdrop. This native adapter does not bind to a global Windows typography variable or promise pixel identity to every private shell component.
3. Wi-Fi, Ethernet, offline, airplane and connecting icons must remain Microsoft's artwork across connection/theme changes, docking and exit. There are no network replacement diagnostics. Existing speaker hiding, battery and Quick Settings click/tooltip behavior should remain.

## 25. Prompt login startup and recovery (0.16.3)

1. After installing, inspect Task Scheduler: jellyflower-<your SID>, logon trigger scoped to your account, no Delay, Run only when user is logged on, normal privileges, enabled, no battery/idle/network restriction, no execution time limit. The Exec action must point to the current version's jellyflower.exe. The Run fallback must point to the same version. No administrator prompt/password should be needed.
2. Restart on AC and sign in normally without launching jellyflower manually. Record time from desktop appearance to frost, tray icon and clock. Inspect diagnostics.log for Started, backend/bridge status and First taskbar appearance request succeeded after ms. That measures controller attachment, not power-on-to-login time or visible blur. Repeat on battery with energy saver, with/without the cursor ZIP, and after a delayed Explorer start. Confirm one controller remains despite both startup paths.
3. Exit restores normal taskbar/clock/cursors and stays exited for this session. Sign out/in restarts normally. Restart Explorer once in a controlled test: TaskbarCreated should promptly retry attachment; no persistent fast polling after attachment or the 30-second window. Solid acrylic under Windows policy remains a separate limitation.
4. With a controlled failed update after startup registration, verify the prior task XML/enabled state, Run value, uninstall record, shortcut and prior controller are restored. A failed first install removes its new task. An obsolete uninstaller must refuse when a newer version owns startup. Uninstall the current version and confirm both its task and Run fallback are absent. Other applications' tasks/Run entries must remain.
5. Windows may display the normal taskbar before Task Scheduler launches the app or Explorer exposes its XAML tree. There is no supported guarantee that a normal-user utility can eliminate every default-taskbar frame. No global startup-delay setting, shell replacement, service or taskbar-hiding trick is used.


## 26. Windows-provided menu typography (0.16.4)

1. Update from 0.16.3 through the version row. On automatic relaunch, confirm v0.16.4 and the earlier menu text appearance. No sign-out, Explorer restart or reboot is needed for this controller-only change.
2. In both themes at 100/125/150/175/200% scaling, check the root menu and cursor submenu for crisp text, complete labels, right-aligned secondary text and centered icons. Font family, size and weight must come from the Windows menu settings; the app no longer defines Fluent Body/Segoe UI Variable/14 DIP/20-DIP line height. Check the native Windows GUI-font fallback if metrics cannot be queried in a controlled test.
3. Confirm acrylic, date, system and update states still render, settings keep the menu open, outside clicks close it, and translucency/hover/entrance animation are retained. The clock, fast login startup, cursor choices and native network icons should behave as in 0.16.3.

## 27. General submenu (0.16.5)

1. The main menu ends with general and its settings gear; update and exit appear only inside it. Test mouse hover/click, Right/Left/Escape, branch switching with cursor, outside clicks and toggling the flower. General must stay open across cursor-pack refreshes even when no pack is installed.
2. The update row shows v0.16.5. Check current/error/checking states and an available newer test release: download is the secondary label; the package opens and the busy icon rotates during checking/downloading/installing. Results update inside general without reopening. A failed check retains the menu.
3. Exit is red in light/dark modes, including hover and keyboard focus; contrast themes use Windows colors. Exit must close both menus and stop the controller through its normal restoration path. Compare both themes at 100/125/150/175/200% DPI. Font metrics are still inherited from Windows.

## 28. Start menu acrylic (0.16.5)

Follow START_MENU.md's acceptance checks for matching colors/stroke, native Start behavior, both themes, scaling, disabled transparency/high contrast, exit/controller-loss restoration, relaunch/update/uninstall, Start host recovery and battery policy. API success is not a visual blur guarantee. No Explorer/Start restart is required when updating from 0.16.4.
