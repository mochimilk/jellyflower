jellyflower 0.16.18

The Start account badge has a smaller 28-DIP avatar (one step down from 32), balanced six-DIP edge padding and a rounder 10-DIP hover container. The native account menu, tooltip, keyboard behavior and typography are retained, with a 40-DIP minimum button height.

Start and Windows Search now use “searching for u 🤍” in dark mode and “searching for u 🖤” in light mode as their empty search placeholder. The heart follows system theme changes while the header is open. Typed text, selection, native search actions and font settings are preserved. Original shell values and bindings restore on exit or controller loss.

Update through general's version/download row. The separate Start/Search v14 helper waits for v13 and older helpers to restore their overrides before connecting, without restarting Start or Search. Explorer v15, the light taskbar's 30% white tint and all other taskbar/menu/wallpaper settings are unchanged; users already running 0.16.17 need no additional sign-out. The x64 installer, portable build and matching source are included.
