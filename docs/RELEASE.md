jellyflower 0.16.22

Pinned apps and folders now have square hover targets that follow their responsive column width, with 12-DIP corners and centered icons. The pinned section height follows the tiles while preserving Windows' collapsed/expanded visible-row count.

The Start footer is 16 DIP taller, with the account badge, shortcuts and power button vertically centered. Shortcut and power hover backgrounds now also use 12-DIP corners. Account padding, avatar size and native actions remain as before.

Search now greets the Windows account first name using local device time: morning from 5am with 🤍, afternoon from noon with 🧸, and evening from 6pm with 😇. Both Start and Search results share the greeting without modifying typed text or adding another timer.

Update through general's version/download row and reopen Start. Start/Search v18 waits for older helpers through v17 to restore before connecting; Explorer stays v15. Users already running 0.16.17 or newer need no additional sign-out. Native layout/restoration, installer payload and update-download checks accompany the x64 installer, portable build and matching source.
