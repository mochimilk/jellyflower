jellyflower 0.16.3

- Use one native equivalent of WinUI's BodyTextBlockStyle for all menu labels: regular Segoe UI Variable, 14 DIP with a 20-DIP line height. DirectWrite selects the installed typographic variable family and automatic optical sizing. Scaling changes pixel size without changing the optical size. Segoe UI remains the compatibility fallback; classic menu metrics are only a GDI failure fallback. This follows the published Fluent role, not a global shell variable or a runtime XAML resource binding.
- Remove the Element 2 Wi-Fi/Ethernet replacement completely, including its selector, callbacks, diagnostics, tests and artwork. Windows supplies all network icons. Existing speaker hiding, battery and Quick Settings behavior remain.
- Start promptly with a per-user Task Scheduler logon task with no added trigger delay. It uses the normal interactive token, allows battery operation, needs no network/idle condition and has no runtime limit. Keep an updated Run fallback for reliability and old-uninstaller ownership checks; the session mutex prevents duplicate controllers. Updates snapshot/restore task XML as well as the prior Run and uninstall records.
- Apply the taskbar before cursor-pack validation and download housekeeping. Retry shell discovery at 100 ms while attaching, for up to 30 seconds; react immediately to TaskbarCreated, then return to ordinary five-second maintenance. Log the first successful appearance request time for diagnosis.

This release uses Explorer helper v13. After upgrading from an earlier loaded helper, sign out and back in once; restarting the computer also loads the new helper and tests the new startup path. Typography applies after app relaunch. Jellyflower does not restart Explorer automatically. Saved settings and imported cursor files are retained. Taskbar tint, menu transparency, spacing and animation are unchanged.

Update from jellyflower's version row, or download jellyflower-setup-x64.exe. Windows can draw the normal taskbar before a login app attaches: this improves startup latency but cannot guarantee zero default-taskbar frames. Cold-boot timing remains a real-desktop acceptance check. The installer is unsigned; corresponding GPL source and notices are included. See VALIDATION.md and INSTALLATION_TESTS steps 24–25.
